تقنية تمنح الحاسوب القدرة على التعلّم من البيانات، وفهم الأنماط، ومساعدة الإنسان في إنجاز مهام متنوعة.

02 — أدوات المبتكرين

لغات تكتب المستقبل

البرمجة هي طريقة نكتب بها تعليمات واضحة للحاسوب. لكل لغة أدواتها واستخداماتها المميزة.

</>01

HTML

هيكل صفحات الويب

ترتب محتوى الصفحة مثل العناوين والفقرات والصور والروابط.

<h1>مرحبًا بالعالم</h1>

تخيّل HTML مثل هيكل المنزل؛ فهي تحدد العناصر التي تظهر في صفحة الويب.

✳02

CSS

تصميم صفحات الويب

تضيف الألوان والتنسيق والمسافات والحركة إلى صفحات الويب.

color: #168bff; ✨

CSS مثل الديكور والألوان؛ تجعل الصفحة أجمل وأسهل في الاستخدام على الشاشات المختلفة.

JS03

JavaScript

التفاعل في صفحات الويب

تضيف التفاعل، مثل القوائم والأزرار والاختبارات القصيرة.

let فكرة = "رائعة";

JavaScript تجعل الصفحة تستجيب للمستخدم، وتنفذ أفعالًا عند الضغط أو الاختيار.

Py04

Python

لغة متعددة الاستخدامات

لغة واضحة للمبتدئين وتستخدم في تحليل البيانات والذكاء الاصطناعي.

print("أهلًا!")

تتميّز Python بسهولة قراءة أوامرها، وتساعد على بناء تطبيقات وأدوات في مجالات كثيرة.

✦ كل مشروع كبير يبدأ بسطر صغير من الشيفرة.
